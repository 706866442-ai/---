# 灰度板 I²C 连通测试

这个测试程序只检查感为八路灰度板是否响应 I²C 地址 0x4C～0x4F，不启动电机，也不读取八路黑白数据。已在本机 PlatformIO/STM32 Arduino 环境编译通过；尚未在实物上验证。

## 供电与接线

- STM32F103C8T6 继续用现有 ST-LINK 的 3.3V 供电，不要把 5V 接到 STM32 的 3V3。
- 灰度板 +5V 接稳定 5V，灰度板 GND 与 STM32/ST-LINK GND 共地。
- 灰度板 SCL → STM32 PB10，灰度板 SDA → STM32 PB11。
- 灰度板 I²C 的 SCL/SDA 必须上拉到 5V；可用板上的对应跳线帽，确认没有重复的强上拉。STM32 的 PB10/PB11 是 5V 耐受引脚，程序通过 I²C 开漏方式使用它们，不开启内部上拉。
- 此直接接法仅针对灰度板单独测试。GY-521 暂不接这条 5V 总线。避免灰度板单独带电、STM32 断电的状态。

## 烧录

1. 在 VS Code 打开本文件所在文件夹 `gray_i2c_probe`。
2. 连接原来的 ST-LINK V2（SWDIO→PA13、SWCLK→PA14、GND→GND、3.3V→STM32 3V3）。先确认 5V 没有误接 STM32 的 3V3。
3. 点击 PlatformIO 的 **Build**（对勾），然后点 **Upload**（向右箭头）。终端显示 `SUCCESS` 即表示烧录完成。
4. 看 STM32 的 PA4 用户 LED：刚启动时先**快速闪三下**，说明新程序开始运行。此后，**每隔约 3 秒快速闪三下**＝灰度板有应答；**亮 3 秒、灭 3 秒**＝未检测到灰度板，先检查灰度板 5V、共地、SCL/SDA 是否接反及上拉跳线。

板上的电源指示灯持续亮并不代表传感器通信成功；只看 PA4 用户灯的闪烁模式。测试通过后，下一步才是读取八路原始数据。
