# 八路灰度读取程序

用于感为 AFA07-S16FCC-00 Rev3.6 与 STM32F103C8T6 C03C 板的单独联调。程序只读取灰度板，不启动电机。工程与原先的 `gray_i2c_probe` 分开保存。

2026-10-13：已在本机编译，并通过 ST-LINK 烧录到 STM32；OpenOCD 返回 `Verified OK`。灰度板尚未接上电源，八路实测数据仍待接线后确认。

程序按传感器手册第 7.7、7.9 和 7.13 节：扫描出厂硬件地址 `0x4C`～`0x4F`，用 `0xAA`/`0x66` 确认设备，然后通过 `0xDD` 读取八路黑白位，通过 `0xB0` 一次读取八路 0～255 原始数值。每 250 ms 读取一次，数字位中 `bit0=第1路`，`1=白`、`0=黑`。模拟数值为原始值，程序没有替你设定循迹阈值。

STM32 板上 PA4 灯：启动时快闪三次；随后亮约 3 秒、灭约 3 秒表示找不到灰度板；每秒约闪四次表示八路数据读取成功。电源灯 L2 不用于判断通信。

详细八路数值通过 STM32 `PA2` 的 3.3V UART TX 输出，速率 115200。需要额外的 USB 转串口设备时，只接 `PA2→转串口 RX`、`公共 GND→转串口 GND`；不要接转串口的 5V/VCC。ST-LINK V2 的 SWD 连接本身不会在 VS Code 中显示这些串口数据。

## 接线（所有电源断开时完成）

| 灰度板长排针标识 | 接到哪里 |
|---|---|
| `SCL` | STM32 `PB10` |
| `SDA` | STM32 `PB11` |
| `GND` | 5V 电源负极，同时接 STM32 `GND` |
| `+5V` | 经测量确认的稳定 5V 电源正极 |

STM32 保持现有 ST-LINK 的 `3V3→3V3`、`GND→GND`、`SWDIO→PA13`、`SWCLK→PA14`。灰度板的 `+5V` 不得接 STM32 `3V3`。灰度板小双排针的 `SCL`、`SDA` 位置是上拉电阻跳线帽位，信号线接长排针；此程序的 I²C 总线需要上拉。仅连接本灰度板时，可以使用其两个 5V/10k 上拉跳线和 STM32 的 5V 耐受 `PB10/PB11`，保持两板同时上电，其他 3.3V I²C 设备不要接入这条总线。此前接线曾冒烟，旧供电线路要先排查并测量，切勿直接复用。

在 VS Code 打开本文件夹，PlatformIO Build 编译，Upload 通过 ST-LINK 烧录。终端出现 `Verified OK` 和 `SUCCESS` 才说明烧录并校验完成。没有看到这些信息时，不能根据亮灯推断烧录成功。
