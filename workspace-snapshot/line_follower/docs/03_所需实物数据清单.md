# 清单三：需要的实物数据与配套资料

日期：2026-10-15。按下列三批收集即可，不必一次性提供全部。数值需带单位，附测量时的起点/车头朝向；测得的值与估计值分开。

## 第一批：先让转弯和双环可靠

| 项目 | 当前已有信息 | 需要补充 / 用途 |
|---|---|---|
| 编码器左右归属 | E1A/E1B接PB13/PB14，E2A/E2B接PB15/PA8，用户确认线已接 | 分别转左、右轮，哪个计数变化，确定E1_IS_RIGHT |
| 编码器比例与正负 | 每圈有效计数尚未验证 | 左右轮各向前手转5圈的起止E1/E2及invalid计数；再反转记录符号。按x4计数，不直接套电机铭牌PPR |
| 编码器电气 | 现有接线记录不代表电平已测 | 编码器供电、输出高低电平、电机运行时信号/错误跳变情况 |
| 轮径、轮距 | 轮径记录65mm；轮距120mm仅估计 | 左右轮实际滚动直径/每圈距离；两轮接地中心间距mm |
| 电机与供电 | A左/B右、两轮正转向前已有用户反馈 | 测试时电池电压、负载条件；各PWM下左右轮一段时间计数/速度、最低稳定转动PWM，用于前馈与PID |
| 灰度位置与赛道 | 1号在车头左侧已有反馈 | 安装高度、探头到轮轴距离、线宽；直线/左右偏/90度角/起点/车位处8位读数序列和视频 |
| 转弯条件 | 尚未实车验证 | 左/右转90度对应两轮计数、实际转角、能重新捕线的读数；转弯时轮胎是否明显打滑 |

建议编码器回复格式：

```text
左轮向前5圈：E1 起__ 止__；E2 起__ 止__；invalid 起__ 止__
右轮向前5圈：E1 起__ 止__；E2 起__ 止__；invalid 起__ 止__
反转符号：左__，右__
轮径/滚动周长：左__mm，右__mm；轮距__mm
```

## 第二批：完整泊车与出库

| 项目 | 需要的数据 | 对应程序 |
|---|---|---|
| 正式赛道/车位 | 原题图或清晰照片；AB是练习侧停还是正式要求DA；各任务从哪里启动、车头朝哪边、车位在行驶方向左还是右 | BAY_SIDE、Approach路径和点序 |
| 车体外形 | 含轮胎的车长/宽；轮轴到车头/车尾距离；明显外伸部件 | 检查是否能入位和转弯扫掠空间 |
| 接近车位 | 起点至首点距离、经过几段；最后一个角点后前移/转向动作；沿目标边前进到泊车基准的距离 | 两套Approach的routeLegs/firstLegMm/corner/followMm |
| 泊车对齐 | 泊车开始前额外前移距离、车头转角；在地面标出轮轴中心 | alignAdvanceMm/alignYawDeg |
| 倒库 | 轮轴到目标停位需倒退距离、车位宽深、最终姿态与边线距离 | REVERSE_DEPTH_MM及验收 |
| 侧停 | 起点相对车位的偏移，所需转弯半径/角度、最终修正前后距离、车位尺寸 | PARALLEL_RADIUS_MM/ANGLE_DEG/TRIM_MM |
| 出库 | 从规定库内姿态直行多少mm、转多少度、再对齐多少mm；加入黑线后先到哪个点、离该点多远、后续点序 | EXIT_FORWARD_MM/TURN_DEG/ALIGN_MM/FIRST_LEG_MM/NEXT_POINT/POINT_STEP |

停车路径验证还需低速视频与最终车身四角位置；仅有轮轴到点不代表车身完全入库。
