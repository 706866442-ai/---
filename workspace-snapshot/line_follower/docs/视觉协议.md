# 视觉协议 v1（待两端确认）

此文件定义本次 STM32 接收器。它不是已有 MaixCAM 模型的已验证输出格式。相机端应先将模型类别映射成下面的值，再调用 tools/vision_packet.py 的 encode 函数或移植等价编码。

## 帧格式

115200 baud，8N1。沿用已存在的 PA3 RX / PA2 TX UART；实物电平、共地及交叉连接仍待核对。视觉启用时 STM32 不发送调试文本。

| 字节 | 含义 |
|---|---|
| 0 | 固定 0xA5 |
| 1 | 版本 0x01 |
| 2 | 类型：1 罗马数字，2 颜色，3 形状 |
| 3 | 该类型递增序号 0～255，允许 255→0 回绕 |
| 4 | 分类值，0 为 UNKNOWN |
| 5 | 置信度 0～100 |
| 6 | CRC8，初值0、多项式0x07、无反射/末异或，覆盖字节1～5 |

数字：1=I→A，2=III→B，3=V→C，4=VII→D。颜色：1红、2黄。形状：1圆、2三角、3方形。不要直接把模型的零基类别编号当作这里的分类值。颜色/形状仅解析，本次尚未接提高题完整任务。

## 接收与决策

- 分包间隔超过100 ms丢弃半帧；CRC、类型、值域错误拒绝。
- 同类型重复/倒退序号拒绝；序号前进差必须1～127。相机重启后需要重新开始任务以重置接收状态。
- 模式7启动清空此前接收缓存；静止等待3帧同类数字，置信度至少80，间隔不超过300 ms。UNKNOWN、低置信度、过期或改变类别重新确认。
- 识别阶段最多10秒；确认后锁定该次任务目标再出库。发车后忽略分类更新，不因途中新卡片改变目的地。
- 该协议没有图像拍摄时间戳，视觉端必须发送当前推理结果；接收新包不能证明图像本身新鲜。

只生成测试帧，不连接设备：

```powershell
& 'C:/Users/0/.platformio/penv/Scripts/python.exe' tools/vision_packet.py --value 3
```

需要串口回放时工具支持显式 --port COMx，要求 pyserial；这会真实发送数据，仅在专用测试场景使用。本次测试未连接串口或发送到车辆。
